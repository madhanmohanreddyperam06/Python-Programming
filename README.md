# Python Programming

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

A collection of Python programming notes and practice examples covering core concepts, data structures, control flow, and Object-Oriented Programming (OOP).

## Topics Covered

- **Basics** — Introduction and overview ([Basics/Python.md](Basics/Python.md))
- **Data Types** — Examples for [List](DataTypes/List/list.py), [Tuple](DataTypes/Tuple/tuple.py), [Set](DataTypes/Set/set.py), and [Dictionary](DataTypes/Dictonary/dict.py)
- **Loops** — [for loop](Loops/for/for.py) and [while loop](Loops/While/while.py) examples
- **Arrays & Strings** — [Max element in array](Arrays/Max.py) and [String reversal](Strings/Reverse.py)
- **Object-Oriented Programming (OOPS)**
  - [Abstraction](OOPS/Abstraction/ATM/atm.py)
  - [Encapsulation](OOPS/Encapsulation/Student/student.py)
  - [Inheritance](OOPS/Inheritance/Parent/parent.py)
  - [Polymorphism](OOPS/Polymorphism/Calulator/calculator.py)

## Running the Examples

Make sure Python 3 is installed, then run any script with:

```bash
python <path-to-script.py>
```
